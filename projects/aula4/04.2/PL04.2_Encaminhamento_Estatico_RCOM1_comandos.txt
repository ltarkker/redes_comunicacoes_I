1. PRESSUPOSTOS
--------------------------------------------------------------------------
- Uma rede classe C (/24) por LAN: 192.168.1.0/24 a 192.168.5.0/24.
- Router = .1 | switch (VLAN 1) = .2 | PCs = .10 e .11.
- Uplink dos switches na Gi0/1; PCs na Fa0/1 e Fa0/2.
- COIMBRA = DCE nas duas ligações série (clock rate 64000).
- consola = cisco | enable secret = class | SSH: admin / qwerty (domínio istec.pt).

5. ROUTERS (PONTOS 3 A 7)
--------------------------------------------------------------------------
Colar no separador CLI a partir do prompt Router> (responder "no" ao diálogo inicial).
A geração da chave RSA demora alguns segundos.

--- PORTO -----------------------------------------------------------------

configure terminal
! 3.1 nome do equipamento
hostname PORTO
no ip domain-lookup
! 3.2 password do modo privilegiado, cifrada
enable secret class
! 3.3 password da consola
line console 0
 password cisco

 logging synchronous

! cifra as passwords em texto simples (consola)
service password-encryption
! 3.4 banner (delimitador #)

9. VERIFICAÇÃO (PONTO 8)
--------------------------------------------------------------------------
Nos routers:
  show ip interface brief          -> Gi e Serial up/up
  show ip route                    -> redes C (ligadas) e S (estáticas)
  show controllers serial 0/0/0    -> no COIMBRA: DCE e clock rate
  show ip ssh                      -> SSH Enabled - version 2.0

No PC1 (Command Prompt):
  ping 192.168.2.10                -> LAN 2 (mesmo router)
  ping 192.168.5.10                -> LAN 5 (uma série)
  ping 192.168.3.10                -> LAN 3 (duas séries)
  ping 192.168.4.11                -> LAN 4 (duas séries)
  tracert 192.168.3.10             -> 192.168.1.1, 14.123.23.2, 15.125.232.2, PC5
  ssh -l admin 192.168.4.2         -> password qwerty; enable pede class
  telnet 192.168.4.2               -> recusado (transport input ssh)

Notas:
- O primeiro ping para cada rede remota pode dar timeout por causa do ARP.
- Se falhar só para algumas redes: rota em falta/next-hop errado num router do
  caminho, ou série sem clock rate no lado DCE.

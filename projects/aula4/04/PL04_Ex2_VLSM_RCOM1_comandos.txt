1. PRESSUPOSTOS
--------------------------------------------------------------------------
- O esquema não vem no ficheiro da ficha; segue-se o que está escrito na ficha:
  R1 Gig0/0 -> SW-PRODUCAO | Gig0/1 -> SW-CONTABILIDADE | Gig0/2 -> SW-VENDAS.
- Um PC por rede, ligado à Fa0/1 de cada switch.
- Passwords: consola = cisco | enable secret = class.

2. A) ENDEREÇAMENTO VLSM
--------------------------------------------------------------------------
Atribuição da maior para a menor rede:
  Vendas         90 hosts -> 2^7 - 2 = 126 -> /25
  Produção       55 hosts -> 2^6 - 2 = 62  -> /26
  Contabilidade  23 hosts -> 2^5 - 2 = 30  -> /27
  Livre: 192.168.100.224/27

               Rede              Máscara                 Broadcast          Intervalo
Vendas         192.168.100.0     255.255.255.128 (/25)   192.168.100.127    .1   - .126
Produção       192.168.100.128   255.255.255.192 (/26)   192.168.100.191    .129 - .190
Contabilidade  192.168.100.192   255.255.255.224 (/27)   192.168.100.223    .193 - .222

Equip.            Interface  IP                Máscara            Gateway
R1                Gig0/0     192.168.100.129   255.255.255.192    -
R1                Gig0/1     192.168.100.193   255.255.255.224    -
R1                Gig0/2     192.168.100.1     255.255.255.128    -
PC-PRODUCAO       Fa0        192.168.100.130   255.255.255.192    192.168.100.129
PC-CONTABILIDADE  Fa0        192.168.100.194   255.255.255.224    192.168.100.193
PC-VENDAS         Fa0        192.168.100.2     255.255.255.128    192.168.100.1

3. B) A G) ROUTER R1
--------------------------------------------------------------------------
--- R1 --------------------------------------------------------------------
Colar no separador CLI a partir do prompt inicial (responder "no" ao diálogo inicial, se aparecer).

enable
configure terminal
! b) nome do equipamento
hostname R1
no ip domain-lookup
! c) password na porta de consola
line console 0
 password cisco
 login
 logging synchronous
 exit
! d) password do modo privilegiado
enable secret class
service password-encryption
! e) banner
banner motd #Atencao! Acesso apenas a pessoal autorizado!#
! f) e g) interfaces e respectivas descrições
interface GigabitEthernet0/0
 description Ligacao a rede PRODUCAO
 ip address 192.168.100.129 255.255.255.192
 no shutdown
 exit
interface GigabitEthernet0/1
 description Ligacao a rede CONTABILIDADE
 ip address 192.168.100.193 255.255.255.224
 no shutdown
 exit
interface GigabitEthernet0/2
 description Ligacao a rede VENDAS
 ip address 192.168.100.1 255.255.255.128
 no shutdown
 exit
end
write memory

5. H) PCS
--------------------------------------------------------------------------
Desktop > IP Configuration > Static, ou Desktop > Command Prompt.
O Command Prompt do PC não aceita várias linhas coladas de uma vez: uma linha por PC.

PC-PRODUCAO:       ipconfig 192.168.100.130 255.255.255.192 192.168.100.129
PC-CONTABILIDADE:  ipconfig 192.168.100.194 255.255.255.224 192.168.100.193
PC-VENDAS:         ipconfig 192.168.100.2 255.255.255.128 192.168.100.1

6. H) VERIFICAÇÃO
--------------------------------------------------------------------------
No R1:
  show ip interface brief      -> Gig0/0, Gig0/1 e Gig0/2 up/up
  show interfaces description  -> alínea g)
  show ip route                -> três redes C (directamente ligadas)

No PC-PRODUCAO (Command Prompt):
  ping 192.168.100.194         -> PC-CONTABILIDADE
  ping 192.168.100.2           -> PC-VENDAS

As três redes estão directamente ligadas ao R1, por isso não são precisas rotas.

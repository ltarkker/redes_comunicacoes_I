Leitura:
- Perdas so na 1.a ronda: cada router no caminho tem de resolver o ARP

- TTL: o PC envia com 128 e cada router desconta 1
  (127 = 1 router, 126 = 2 routers). Os routers respondem com 255.

10. NOTAS - ERROS QUE APARECERAM E COMO SE RESOLVERAM
--------------------------------------------------------------------------
- "Invalid File ... corrupted Physical Workspace data" ao abrir o .pkt:
  erro no ficheiro gerado (caminho fisico dos equipamentos no rack).
  Corrigido na versao actual do .pkt.

- "% Invalid input" com prompt ">": comando de modo privilegiado em
  modo utilizador. Correr "enable" primeiro.

- "Translating ... domain server (255.255.255.255)": comando
  desconhecido tratado como nome de host. Ctrl+Shift+6 interrompe;
  "no ip domain-lookup" resolve de vez. Acontece tambem com "end" em
  modo # (o "end" so existe nos modos (config)#).

- "% ... overlaps with ...": a mesma rede, ou uma que se sobrepoe, ja
  esta noutra interface. Retirar primeiro com "no ip address" na
  interface antiga. Ex.: 192.168.0.129 com /26 cobre .128-.191 e apanha
  o link RT .184/30; o Marketing tem de ser /27 (255.255.255.224).

- Mascara com 5 octetos (255.255.255.255.0): "% Invalid input".

- Colar "enable" seguido de mais linhas quando ja existe enable secret:
  a linha seguinte e consumida como password. Fazer o enable a mao.

- "show ip brief": comando incompleto. Forma abreviada correcta:
  "sh ip int br".

- "ip config" no PC: "Invalid Command". O comando e "ipconfig".

- Varias linhas coladas de uma vez no Command Prompt do PC: juntam-se
  numa so linha e dao "Invalid Command". Colar uma linha de cada vez.

- PC com Default Gateway 0.0.0.0 apesar do ipconfig com 3 argumentos:
  ping ao proprio gateway OK, pings para outras redes "Request timed
  out" (o destino recebe o pedido mas nao tem por onde responder).
  Resolvido preenchendo o Default Gateway em IP Configuration.

- Link-local IPv6 igual em todos os PCs: campo copiado do modelo ao
  gerar o .pkt. Corrigido no ficheiro final (sem impacto em IPv4).

- Historico do Edificio-1: passou por duas distribuicoes provisorias
  antes da final da ficha. A secao 3 ja reflecte o estado final; a
  secao 5 e o bloco que fez a mudanca.
